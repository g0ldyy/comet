# Configuration Model and Environment Variables

## Source of Truth

For runtime behavior, use `AppSettings` in `comet/core/models.py` as authoritative.

Practical rule:

- `comet/core/models.py`: real defaults and parsing behavior.
- `.env-sample`: human template and comments.

## Important Parsing Behavior

`AppSettings` applies normalization and compatibility logic:

- Empty environment values keep the modeled default, so empty assignments in
  `.env-sample` are safe to copy.
- URL settings have trailing `/` removed.
- URL list entries may include an instance mode suffix (`:live`, `:background`, `:both`).
- `DATABASE_TYPE` aliases (`postgres`, `pgsql`, `sqlite3`, etc.) are normalized.
- Scraper context mode supports `true/both/live/background/false`.
- `PUBLIC_API_TOKEN` and `PUBLIC_API_TOKEN_FILE` support auto-generation when API protection is enabled.
- Optional secret-like fields treat empty/`none` as unset.
- `LOG_PROFILE` accepts only `quiet`, `normal`, `verbose`, or `debug`;
  `LOG_FORMAT` accepts only `pretty` or `json`.

## Stremio API Prefix Protection

`STREMIO_API_PREFIX` is generated when either is set:

- `CONFIGURE_PAGE_PASSWORD`
- `PUBLIC_API_TOKEN`

Behavior:

- Protected prefix format: `/s/<token>`
- Token can come from env, token file, or be auto-generated/persisted

## High-Impact Configuration Groups

1. Server/runtime
- `FASTAPI_HOST`, `FASTAPI_PORT`, `FASTAPI_WORKERS`
- `USE_GUNICORN`, `GUNICORN_PRELOAD_APP`
- `EXECUTOR_MAX_WORKERS`

2. Security/UI access
- `ADMIN_DASHBOARD_PASSWORD`, `ADMIN_DASHBOARD_SESSION_TTL`
- `CONFIGURE_PAGE_PASSWORD`, `CONFIGURE_PAGE_SESSION_TTL`
- `PUBLIC_API_TOKEN`, `PUBLIC_API_TOKEN_FILE`

Configured secret values are read once and never printed. Auto-generated
operator secrets are emitted as `config.generated_secret` during startup so
the operator can use them. Secrets generated by the settings bootstrap are
stored in the shared database and remain consistent across replicas.

3. Database/cache
- `DATABASE_TYPE`, `DATABASE_URL`, `DATABASE_PATH`
- `DATABASE_READ_REPLICA_URLS`, `DATABASE_FORCE_IPV4_RESOLUTION`
- `METADATA_CACHE_TTL`, `TORRENT_CACHE_TTL`, `LIVE_TORRENT_CACHE_TTL`, `DEBRID_CACHE_TTL`

4. Streaming and proxy
- `PROXY_DEBRID_STREAM`
- `PROXY_DEBRID_STREAM_PASSWORD`
- `PROXY_DEBRID_STREAM_MAX_CONNECTIONS`
- `DISABLE_TORRENT_STREAMS`

5. Scrapers/indexers
- `SCRAPE_*` flags and related URL/API key variables
- `LIVE_SCRAPE_TIMEOUT`, `BACKGROUND_SCRAPE_TIMEOUT`
- `SCRAPER_TIMEOUT_OVERRIDES`
- Jackett/Prowlarr indexer manager settings
- `INDEXER_INCLUDE_CANONICAL_TITLE`: includes Comet's canonical metadata title. Defaults to `True`.
- `INDEXER_INCLUDE_ORIGINAL_TITLE`: includes one original TMDB or anime-mapping title. Defaults to `True`.
- `INDEXER_LANGUAGES`: includes at most one TMDB title per configured ISO 639-1 language. Defaults to `[]`.

These sources are independent and apply to every title-based scraper. Latin diacritics are removed from search titles for broader indexer compatibility, while non-Latin writing systems are preserved. Equivalent titles are deduplicated, and Comet safely falls back to the canonical title if the selected sources produce no usable title.

6. Usenet
- `USENET_ENABLED`: exposes Usenet discovery and playback configuration.
- `USENET_ENGINE_ENABLED`: starts the optional built-in NNTP/archive/PAR2
  engine; it requires `USENET_ENABLED`.
- `USENET_ENGINE_REQUIRED`: makes an engine startup failure fatal instead of
  leaving external/client providers available.
- `USENET_NATIVE_ACCESS_TOKEN`: authorizes an addon profile to select an
  operator-offered built-in NNTP source. When omitted while Usenet is enabled,
  Comet generates it in the shared database and emits it as
  `config.generated_secret`.
- `USENET_NATIVE_SERVERS`: operator-owned NNTP servers available as the
  instance pool.
- `USENET_NATIVE_ALLOW_USER_SERVERS`: permits personal NNTP servers in addon
  configuration.
- `USENET_PRIVATE_UPSTREAM_ORIGINS`: exact explicit-port HTTP(S) origins that
  may resolve to private addresses for configured local indexers or bridges.
- `COMET_CAPABILITY_SECRET` / `COMET_CAPABILITY_SECRET_FILE`: signing key
  source. A persistent single-replica deployment can use the generated file;
  replicas without shared storage must use one explicit shared secret.
- `USENET_REPLICA_COUNT`: declared replica count. More than one replica
  requires PostgreSQL.
- Runtime, artifact and local-data paths plus memory, disk, spool, stream,
  preparation, archive, repair, startup and drain limits use the
  `USENET_*` settings documented in `.env-sample`.

The built-in engine requires host-kernel Landlock ABI 3 or newer and fails
closed when archive/PAR2 workers cannot be confined. External providers and
Stremio NNTP handoff do not require the engine.

7. Background jobs
- `BACKGROUND_SCRAPER_*`
- `DMM_INGEST_*`
- `DEBRID_ACCOUNT_SCRAPE_*`

8. CometNet
- `COMETNET_*` (documented separately in `docs/cometnet/`)

9. Observability
- `LOG_PROFILE`, `LOG_FORMAT`
- `PROMETHEUS_ENABLED`, `PROMETHEUS_PATH`
- `PROMETHEUS_AUTH_TOKEN`, `PROMETHEUS_AUTH_TOKEN_FILE`
- `PROMETHEUS_MULTIPROC_DIR`
- Full setup and metric catalog: [Prometheus and Grafana Observability](07-observability.md)
- Runtime events and diagnostic workflow:
  [Logging and Diagnostics](08-logging-and-diagnostics.md)

## Backward-Compatibility Settings

`INDEXER_MANAGER_TYPE`, `INDEXER_MANAGER_URL`, and related `INDEXER_MANAGER_*` values are still supported in runtime and mapped into Jackett/Prowlarr settings in `model_post_init`.

## Recommendation for Operators

- Keep a small `.env` containing only overrides.
- Use `.env-sample` as a catalog of available keys.
- Validate high-risk settings (workers, DB type, proxy, CometNet mode) before production rollout.
